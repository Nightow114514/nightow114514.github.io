Features

六个能力，组成完整的错题闭环

没有花哨功能，每个设计都围绕一件事：让你把错题真正吃透。

一键录入

按 Ctrl+Shift+E 依次填写题号、考点、错因、难度、答案，自动生成带 frontmatter 的错题笔记，粘贴截图即可保存。

错题仪表盘

今日待复习、掌握程度分布、难度分布、薄弱考点 TOP 10、错因分布、每周新增趋势，打开一眼看清问题在哪。

随机组卷

按难度、掌握程度、考点、错因自由筛选；默认只抽到期的题，并保证 2 天内不重复抽到同一道。

智能复习调度

标记掌握程度时自动安排下次复习：未掌握 1 天，之后按 3 → 7 → 15 → 30 天递进，遵循记忆规律。

错因与复盘

录入时记录错因（概念不清、计算失误、思路中断…），每道题内置「我的复盘」区，复习后沉淀正确思路。

FAQ

常见问题

关于数据、插件和日常使用，你可能想知道的都在这里。

需要自己安装插件吗？
不需要。仓库里的 .obsidian 已预装 Dataview、Templater、QuickAdd 及全部配置，用 Obsidian 打开 Vault 后确认三个插件开关为绿色即可。
错题数据存在哪里？会传到 GitHub 吗？
所有笔记和截图都以 Markdown 文件保存在本地。仓库已配置 git 忽略规则，错题本/ 和 错题原图/ 里的个人数据不会上传，只在你的设备上。
会连续抽到同一道题吗？
默认不会。做完一组卷子后点击「✅ 本次已做完」，抽中的题会记下日期，2 天内不再被抽到。想调整可在组卷文件顶部把 skip-recent-days 改为其他天数。
换电脑或发给别人怎么迁移？
直接复制整个项目文件夹即可，配置都在 .obsidian 里。也可以用 Obsidian Sync 或 Git 同步，个人笔记会随仓库规则继续被忽略。
旧错题会出现在「今日待复习」里吗？
会。没有设置复习日期的旧题会按“已到期”处理，优先进入今日待复习；复习一次并标记掌握程度后，系统就会自动安排后续复习日期。
